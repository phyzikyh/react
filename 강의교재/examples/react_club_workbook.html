PART 01

머리말과 메뉴 (Header)

함수 컴포넌트classNamenav
목표 화면 — 이렇게 보이도록 만드세요

미션

화면 맨 위에 로고와 메뉴 바를 만듭니다. JSX에서는 class 대신 className을 씁니다.

요구사항

  • 왼쪽 로고 <CodeMate/> (꺾쇠는 &lt; &gt;)
  • 오른쪽 메뉴 4개 (소개·활동·모집·문의)
  • 스크롤해도 위에 고정
먼저: 화면에 쓸 값 준비 (App.jsx 위쪽)
src/App.jsx값 준비
// App.jsx 위쪽에 화면에 표시할 값을 준비합니다.
const club = {
  name: "CodeMate",
  slogan: "함께 만들고 함께 성장하는 대학 개발 동아리",
  intro:
    "CodeMate는 웹과 앱을 직접 만들어 보며 실력을 키우는 동아리입니다. 매주 스터디로 기초를 다지고, 학기마다 팀을 이루어 실제 서비스를 완성합니다.",
  foundedYear: 2019,
  memberCount: 48,
  projectCount: 27,
};

const study = { title: "주간 스터디", desc: "매주 한 가지 주제를 함께 학습하고 코드 리뷰를 진행합니다.", tag: "매주 화요일" };
const project = { title: "팀 프로젝트", desc: "학기마다 3~4인 팀을 구성해 기획부터 배포까지 경험합니다.", tag: "학기 단위" };
const hackathon = { title: "해커톤", desc: "방학마다 무박 2일 해커톤으로 아이디어를 서비스로 만듭니다.", tag: "방학 특별활동" };

const thisYear = 2026;

PART 02

소개 배너 (Hero)

중괄호 {}객체 값버튼
목표 화면 — 이렇게 보이도록 만드세요

미션

첫 화면에 동아리 한 줄 소개와 버튼을 배치합니다. 제목·설명은 club 객체에서 값을 꺼내 표시합니다.

요구사항

  • SINCE 연도, 큰 슬로건, 소개 문단
  • 버튼 2개 (채운 것·테두리 것)
  • 모든 텍스트는 club 값에서 {} 로 표시
Hero 컴포넌트 — App.jsx 에 추가
src/App.jsx그대로 작성
function Hero() {
  return (
    <section className="hero" id="home">
      <div className="wrap">
        <p className="eyebrow">SINCE {club.foundedYear}</p>
        <h1 className="hero-title">{club.slogan}</h1>
        <p className="hero-desc">{club.intro}</p>
        <div className="hero-buttons">
          <a className="btn btn-fill" href="#recruit">지원하기</a>
          <a className="btn btn-line" href="#activities">활동 살펴보기</a>
        </div>
      </div>
    </section>
  );
}
PART 03

소개와 숫자 (About)

산술식 {}통계
목표 화면 — 이렇게 보이도록 만드세요

미션

소개 문단과 숫자 통계를 만듭니다. 활동 연차는 값을 직접 적지 않고 올해 - 창립연도로 계산합니다.

요구사항

  • 섹션 제목 + 소개 문단
  • 통계 3칸 (연차·회원·프로젝트)
  • 연차는 {thisYear - club.foundedYear} 로 계산
About 컴포넌트 — App.jsx 에 추가
src/App.jsx그대로 작성
function About() {
  return (
    <section className="section" id="about" aria-labelledby="about-title">
      <div className="wrap">
        <h2 className="section-title" id="about-title">소개</h2>
        <p className="lead">{club.intro}</p>
        <ul className="stats">
          <li className="stat">
            <strong className="stat-num">{thisYear - club.foundedYear}년</strong>
            <span className="stat-label">활동 연차</span>
          </li>
          <li className="stat">
            <strong className="stat-num">{club.memberCount}명</strong>
            <span className="stat-label">함께하는 회원</span>
          </li>
          <li className="stat">
            <strong className="stat-num">{club.projectCount}개</strong>
            <span className="stat-label">완성한 프로젝트</span>
          </li>
        </ul>
      </div>
    </section>
  );
}

미션

설명 목록(dl)으로 모집 정보를 정리합니다. 제목의 연도는 {thisYear} 값으로 표시합니다.

목표 화면 — 이렇게 보이도록 만드세요

미션

입력 양식을 만듭니다. label은 for 대신 htmlFor를 쓰고, 그 값과 input의 id가 같아야 합니다.

요구사항

  • 입력 3개 (이름·이메일·메시지) + 각 라벨
  • htmlFor 값과 input id 일치
  • 빈 요소 input 은 /> 로 닫기
Contact 컴포넌트 — App.jsx 에 추가
src/App.jsx그대로 작성
function Contact() {
  return (
    <section className="section section-alt" id="contact" aria-labelledby="contact-title">
      <div className="wrap">
        <h2 className="section-title" id="contact-title">문의하기</h2>
        <p className="lead">궁금한 점이나 지원 의사를 편하게 남겨 주세요.</p>
        <form className="form">
          <div className="field">
            <label htmlFor="name">이름</label>
            <input id="name" type="text" placeholder="홍길동" />
          </div>
          <div className="field">
            <label htmlFor="email">이메일</label>
            <input id="email" type="email" placeholder="you@example.com" />
          </div>
          <div className="field">
            <label htmlFor="message">메시지</label>
            <textarea id="message" placeholder="하고 싶은 말을 적어 주세요." />
          </div>
          <button className="btn btn-fill" type="button">보내기</button>
        </form>
      </div>
    </section>
  );
}
