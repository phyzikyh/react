# 7주차 참고문헌

「7주차: 조건부 렌더링과 리스트」의 React 동작과 JavaScript 배열 메서드를 확인하기 위해 공식 문서를 참고했습니다. 2026년 10월 6일에 확인했습니다.

## React 공식 문서

1. React, **Conditional Rendering**

   `if`, 삼항 연산자, `&&`, JSX 변수 및 `null`을 사용해 조건에 따라 화면을 표시하는 방법을 참고했습니다.
   <https://react.dev/learn/conditional-rendering>

2. React, **Rendering Lists**

   `map()`과 `filter()`로 화면 목록을 만들고, 안정적인 `key`로 항목을 구분하는 방법을 참고했습니다.
   <https://react.dev/learn/rendering-lists>

3. React, **Choosing the State Structure**

   Props나 기존 State에서 계산할 수 있는 값을 중복 State로 저장하지 않는 원칙을 참고했습니다.
   <https://react.dev/learn/choosing-the-state-structure>

## JavaScript 참고 문서

4. MDN Web Docs, **Array.prototype.map()**

   `map()`이 배열 원소마다 변환 함수를 적용해 새 배열을 반환하는 동작을 참고했습니다.
   <https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/map>

5. MDN Web Docs, **Array.prototype.filter()**

   `filter()`가 조건을 통과한 원소로 새 배열을 만드는 동작을 참고했습니다.
   <https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/filter>
