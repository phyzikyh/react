JSX로 구현하는 온라인 서점

공개

2026년 9월 9일

도서 홈페이지

머리말, 메뉴·검색, 카테고리, 도서 5권의 목록, 가격 정보, 바닥글로 구성된 온라인 서점 화면을 React로 만듭니다.

코드는 src/App.jsx에 작성합니다. 변수는 App 함수의 return 위에, 각 영역의 JSX는 return (...) 안에 배치합니다.

CSS와 표지 파일의 App.css는 src 폴더에, 표지 파일 5개는 public 폴더에 저장합니다. src/index.css의 기본 템플릿 스타일은 비워 둡니다.

실행 결과

App.jsx의 기본 구조

import "./App.css";

function App() {
  const storeName = "BOOKMARKET";

  return (
    <>
      {/* 머리말 */}
      {/* 본문 */}
      {/* 바닥글 */}
    </>
  );
}

export default App;

머리말, 본문, 바닥글은 Fragment 안에 나란히 배치합니다. 각 영역의 코드는 해당 주석 위치에 작성합니다.

이 코드에 쓰인 문법

  • import "./App.css"; — 같은 폴더의 CSS 파일을 불러옵니다.
  • function App() { — JSX를 반환하는 함수 컴포넌트를 정의합니다.
  • const storeName = "BOOKMARKET"; — 서점 이름을 문자열 변수에 저장합니다.
  • return ( — 화면 구조를 설명하는 JSX를 반환합니다.
  • <>와 </> — 여러 최상위 요소를 하나의 Fragment 표현식으로 묶습니다. 실제 DOM에 묶음 태그를 추가하지 않습니다.
  • {/* 머리말 */} — JSX 주석이며 화면에 표시되지 않습니다.
  • ); — 반환문을 마칩니다.
  • } — 함수 정의를 마칩니다.
  • export default App; — 다른 파일에서 App을 가져올 수 있도록 내보냅니다.

머리말: 로고와 검색창

<header className="store-header">
  <div className="header-inner">
    <a className="brand" href="#top">{storeName}</a>
    <div className="search-box">
      <label htmlFor="keyword">도서 검색</label>
      <input
        id="keyword"
        type="search"
        placeholder="어떤 책을 찾고 있나요?"
      />
    </div>
    <span className="header-note">책과 함께하는 일상</span>
  </div>
</header>

서점 로고와 검색 입력란을 머리말에 표시합니다. 레이블을 클릭하면 연결된 입력란에 초점이 이동합니다.

이 코드에 쓰인 문법

  • <header className="store-header"> — 머리말을 만들고 .store-header 스타일을 적용합니다. JSX의 CSS 클래스 속성은 className입니다.
  • <div className="header-inner"> — 로고와 검색창을 같은 가로 영역에 배치하는 스타일을 연결합니다.
  • <a className="brand" href="#top">{storeName}</a> — 변수에 저장한 서점 이름을 링크로 표시합니다. #top은 id="top"인 본문으로 이동하는 주소입니다.
  • <div className="search-box"> — 레이블과 입력란을 묶습니다.
  • <label htmlFor="keyword">도서 검색</label> — id="keyword"인 입력란과 연결합니다. JSX에서는 HTML의 for 대신 htmlFor를 사용합니다.
  • <input — 입력 요소를 시작합니다.
  • id="keyword" — 레이블의 htmlFor와 일치하는 식별 이름입니다.
  • type="search" — 검색어를 입력하는 요소입니다.
  • placeholder="어떤 책을 찾고 있나요?" — 입력값이 비어 있을 때 표시할 문구입니다.
  • /> — 자식 내용이 없는 입력 요소를 닫습니다.
  • <span className="header-note">책과 함께하는 일상</span> — 머리말의 짧은 소개 문구입니다.
  • </div>, </header> — 안쪽 영역부터 순서대로 닫습니다.

메뉴: 도서 영역으로 이동

header-inner 다음, header 안에 배치합니다.

<nav className="store-nav" aria-label="서점 메뉴">
  <a className="selected" href="#books">베스트셀러</a>
  <a href="#book1">문학</a>
  <a href="#book3">인문</a>
  <a href="#book4">희곡</a>
  <a href="#book5">과학</a>
  <a href="#store-info">서점 안내</a>
</nav>

각 메뉴는 같은 페이지의 해당 도서 또는 안내 영역으로 이동합니다. href의 # 뒤 문자열과 목적지의 id가 연결됩니다.

이 코드에 쓰인 문법

  • <nav className="store-nav" aria-label="서점 메뉴"> — 메뉴를 묶습니다. aria-label은 보조 기술에 메뉴 이름을 전달합니다.
  • className="selected" — 베스트셀러 메뉴에 선택 상태의 스타일을 적용합니다.
  • href="#books" — 도서 목록으로 이동합니다.
  • href="#book1" — 첫 번째 문학 도서로 이동합니다.
  • href="#book3" — 인문 도서로 이동합니다.
  • href="#book4" — 희곡 도서로 이동합니다.
  • href="#book5" — 과학 도서로 이동합니다.
  • href="#store-info" — 서점 안내로 이동합니다.
  • </nav> — 메뉴 영역을 닫습니다.

본문: 카테고리와 목록 배치

머리말 다음에 배치합니다.

<main className="store-layout" id="top">
  <aside className="sidebar">
    {/* 카테고리 */}
  </aside>

  <section className="catalog" id="books">
    {/* 목록 제목 */}
    <div className="book-list">
      {/* 도서 5권 */}
    </div>
  </section>
</main>

본문은 왼쪽 카테고리와 오른쪽 도서 목록으로 나뉩니다. JSX는 영역의 구조를 정의하며 두 열의 너비와 간격은 CSS에서 지정합니다.

이 코드에 쓰인 문법

  • <main className="store-layout" id="top"> — 본문을 만들고 두 열 배치 스타일을 연결합니다.
  • <aside className="sidebar"> — 보조 탐색 영역인 카테고리를 담습니다.
  • <section className="catalog" id="books"> — 도서 목록을 묶습니다. books는 베스트셀러 메뉴의 목적지입니다.
  • <div className="book-list"> — 도서 항목 5개를 담습니다.
  • {/* ... */} — 각 코드가 들어갈 위치를 나타내는 주석입니다.
  • </div>, </section>, </main> — 목록에서 본문 순서로 닫습니다.

카테고리: 분야와 도서 수 표시

aside 안에 작성합니다.

<h2>도서 카테고리</h2>
<nav aria-label="도서 분야">
  <a className="active" href="#books">전체 도서 <span>5</span></a>
  <a href="#book1">문학 <span>2</span></a>
  <a href="#book3">인문 <span>1</span></a>
  <a href="#book4">희곡 <span>1</span></a>
  <a href="#book5">과학 <span>1</span></a>
</nav>
<p className="sidebar-note">한 권의 책으로<br />넓어지는 나의 세계</p>

분야별 도서 수를 링크 옆에 표시합니다. 문학은 2권이며 인문, 희곡, 과학은 각각 1권입니다.

이 코드에 쓰인 문법

  • <h2>도서 카테고리</h2> — 카테고리 제목입니다.
  • <nav aria-label="도서 분야"> — 분야별 링크를 묶습니다.
  • className="active" — 전체 도서 항목에 강조 스타일을 적용합니다.
  • href="#books" — 전체 목록으로 이동합니다.
  • href="#book1", href="#book3", href="#book4", href="#book5" — 분야에 해당하는 도서 위치로 이동합니다.
  • <span>5</span> — 총 도서 수를 링크 글자와 구분하여 스타일을 적용할 수 있게 묶습니다.
  • <span>2</span>, <span>1</span> — 분야별 도서 수입니다.
  • <p className="sidebar-note"> — 카테고리 아래의 소개 문단입니다.
  • <br /> — 문단 안에서 줄을 바꿉니다. 자식이 없는 태그이므로 />로 닫습니다.

  • <p className="breadcrumb"> — 현재 위치를 나타내는 문단입니다.

  • <strong>5</strong> — 전체 도서 수를 강조합니다.
  • <span>추천 도서</span> — 목록의 성격을 표시합니다.

도서 1: 이상한 나라의 앨리스

변수는 App 함수의 return 위에 작성합니다.

const title1 = "이상한 나라의 앨리스";
const author1 = "Lewis Carroll";
const price1 = 15000;
const discount1 = 1500;

제목과 저자는 문자열, 정가와 할인 금액은 숫자로 저장합니다.

이 코드에 쓰인 문법

  • const title1 = "이상한 나라의 앨리스"; — 도서 제목을 저장합니다.
  • const author1 = "Lewis Carroll"; — 저자 이름을 저장합니다.
  • const price1 = 15000; — 정가를 숫자로 저장합니다.
  • const discount1 = 1500; — 정가에서 뺄 할인 금액입니다.

book-list 안에 작성합니다.

<article className="book-row" id="book1">
  <span className="rank">1</span>
  <img className="cover" src="./store-book-1.svg" alt={title1} />
  <div className="book-details">
    <span className="category">문학</span>
    <h2>{title1}</h2>
    <p className="author">{author1}</p>
    <p className="description">상상으로 가득한 세계에서 펼쳐지는 앨리스의 모험.</p>
    <p className="price-line">
      <span className="discount">10%</span>
      <strong>{price1 - discount1}원</strong>
      <del>{price1}원</del>
    </p>
    <p className="shipping">무료배송</p>
  </div>
</article>

표지 옆에 제목, 저자, 소개와 가격을 표시합니다. 판매가는 15000 - 1500을 계산한 13500원입니다.

이 코드에 쓰인 문법

  • <article className="book-row" id="book1"> — 한 권의 도서를 묶습니다. id는 메뉴에서 이 도서로 이동할 때 사용하는 이름입니다.
  • <span className="rank">1</span> — 목록에서의 순위를 표시합니다.
  • <img className="cover" src="./store-book-1.svg" alt={title1} /> — 표지 파일을 표시합니다. src는 이미지 경로이고 alt는 제목 변수를 이용한 대체 설명입니다. 자식이 없는 img는 />로 닫습니다.
  • <div className="book-details"> — 제목과 가격 등 도서 정보를 묶습니다.
  • <span className="category">문학</span> — 도서의 분야를 표시합니다.
  • <h2>{title1}</h2> — 중괄호로 제목 변수의 값을 표시합니다.
  • <p className="author">{author1}</p> — 저자 이름을 표시합니다.
  • <p className="description"> — 도서 소개 문단입니다. 태그 사이의 고정 문장을 그대로 표시합니다.
  • <p className="price-line"> — 할인율, 판매가, 정가를 묶습니다.
  • <span className="discount">10%</span> — 할인율 안내입니다. 이 도서의 할인 금액은 정가의 10%입니다.
  • <strong>{price1 - discount1}원</strong> — 중괄호 안의 뺄셈 결과를 강조하여 표시합니다. 원은 고정 단위입니다.
  • <del>{price1}원</del> — 정가를 취소선으로 표시합니다.
  • <p className="shipping">무료배송</p> — 배송 안내 문구를 표시합니다.
  • </div>, </article> — 도서 정보 영역과 도서 항목을 차례로 닫습니다.

실습: 독서모임 안내

각 문제를 별도의 App.jsx 코드로 작성합니다.

문제 1. 모임 소개

다음 내용을 표시하는 소개 영역을 작성하세요.

항목 내용
모임 이름 토요일 독서모임
모임 날짜 2026년 10월 17일
장소 도서관 세미나실
  • 모임 이름, 날짜, 장소를 각각 문자열 변수에 저장합니다.
  • 모임 이름은 제목으로, 날짜와 장소는 문단으로 표시합니다.
  • 세 요소를 section 하나로 묶습니다.

문제 2. 모집 현황

정원은 8명, 신청 인원은 5명입니다. 두 값을 숫자 변수로 저장하고 정원, 신청 인원, 남은 자리를 표시하세요.

  • 남은 자리는 중괄호 안의 뺄셈으로 계산합니다.
  • 기본 결과는 3명입니다.
  • 정원을 10으로 바꾸면 JSX의 계산식을 수정하지 않아도 남은 자리가 5명으로 표시되어야 합니다.

문제 3. 참가자 입력란

이름과 이메일을 입력하는 영역을 작성하세요.

  • 이름에는 type="text", 이메일에는 type="email"을 사용합니다.
  • 입력란마다 서로 다른 id를 지정합니다.
  • 각 입력란에 label을 연결합니다.
  • 레이블을 클릭하면 대응하는 입력란으로 초점이 이동해야 합니다.
  • 입력란을 div 하나로 묶고 className="search"를 적용합니다.
