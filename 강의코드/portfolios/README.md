# 🎓 개인 포트폴리오 프로젝트 템플릿 (난이도별 3종)

1주차(HTML 시맨틱 웹)와 2주차(CSS 박스모델, Flexbox, Grid, 반응형 웹) 내용을 기반으로 제작된 실습용 포트폴리오 프로젝트입니다.

---

## 📁 디렉토리 구조 및 난이도 안내

```text
portfolios/
├── 1_basic/            # [하] 초급: 심플 시맨틱 포트폴리오 (기초 웹 표준)
│   ├── index.html
│   └── style.css
│
├── 2_intermediate/     # [중] 중급: 모던 반응형 카드 그리드 포트폴리오 (Sticky, Flexbox, Grid)
│   ├── index.html
│   └── style.css
│
└── 3_advanced/         # [상] 고급: 다크모드 대응 테크 포트폴리오 (다크모드, clamp, 키프레임)
    ├── index.html
    └── style.css
```

---

## 🚀 실행 방법
각 폴더의 `index.html` 파일을 브라우저(크롬, 엣지 등)로 더블 클릭하여 열거나, VS Code의 **Live Server** 확장을 사용하여 실행합니다.
