PART 00

프로젝트 준비

파일 하나HTML 뼈대내부 style

미션

index.html 파일 하나를 만듭니다. CSS는 <head> 안의 <style> 태그에, HTML은 <body> 안에 작성합니다. 파일 하나만 브라우저로 열면 내용과 스타일이 바로 함께 보입니다. 아래 시작 코드를 그대로 작성하고 시작하세요.

요구사항

  • 파일 하나만 만들기: index.html
  • <head> 안에 <style> ... </style> 넣기
  • <style> 맨 위에 기본 설정(초기화) 작성
시작 파일 (그대로 작성)
index.html새 파일 — 이대로 시작
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>홍길동 · dev</title>
  <style>
/* ===== 기본 설정 ===== */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

body {
  font-family: 'Segoe UI', 'Malgun Gothic', sans-serif;
  color: #1f2328;
  background-color: #fbfcfd;
  line-height: 1.7;
}

a {
  color: inherit;
  text-decoration: none;
}

/* 내용을 가운데로 모으는 상자 */
.wrap {
  max-width: 1000px;
  margin: 0 auto;
  padding: 0 24px;
}
  </style>
</head>
<body>

  <!-- 아래에 PART 1부터 순서대로 HTML을 추가합니다 -->

</body>
</html>
PART 01

네비게이션 바

flexboxposition:sticky
목표 화면 — 이렇게 보이도록 만드세요

미션

화면 맨 위에, 왼쪽 로고와 오른쪽 메뉴가 양 끝으로 벌어진 고정 바를 만드세요.

요구사항

  • 왼쪽: <홍길동/> 로고 (/ 는 초록색)
  • 오른쪽: 메뉴 6개
  • 스크롤해도 맨 위에 고정
  • 메뉴 글자 앞에 ~/ 붙이기

HTML 구조 — 이렇게 만드세요

  • <nav class="nav"> 안에 <div class="wrap nav-inner"> 를 넣습니다
  • 왼쪽 로고: <div class="brand"> — 텍스트는 홍길동, 가운데 / 는 <span class="slash">/</span> 로 (꺾쇠 &lt; &gt; 는 그대로 입력)
  • 오른쪽 메뉴: <ul> 안에 <li><a href="#about">about</a></li> 형태로 6개 (about, skills, career, work, blog, contact)

CSS 지시 — <style> 안에 아래 값 그대로 작성하세요

  • .navposition: sticky; top: 0; background-color: #ffffff; border-bottom: 1px solid #e3e7ec;
  • .nav-innerdisplay: flex; justify-content: space-between; align-items: center; height: 62px;
  • .brandfont-family: monospace; font-weight: bold; font-size: 16px;
  • .brand .slashcolor: #16a34a;
  • .nav uldisplay: flex; gap: 22px; list-style: none; font-family: monospace; font-size: 14px; color: #636c76;
  • .nav a::beforecontent: "~/"; color: #c8cdd4;
  • .nav a:hovercolor: #16a34a;
