# 3주차 참고문헌

이 문서는 「3주차: JSX와 엘리먼트 렌더링」을 작성할 때 확인한 자료를 정리한 것입니다. 공식 문서를 우선하여 사용했으며, 2026년 9월 8일에 확인했습니다.

## React 공식 문서

1. React, **Writing Markup with JSX**  
   JSX의 정의, JSX를 사용하는 이유, 하나의 루트 요소, 태그 닫기와 JSX 기본 규칙을 참고했습니다.  
   <https://react.dev/learn/writing-markup-with-jsx>

2. React, **JavaScript in JSX with Curly Braces**  
   JSX 안에서 변수, 표현식, 속성값과 JavaScript 객체를 사용하는 방법을 참고했습니다.  
   <https://react.dev/learn/javascript-in-jsx-with-curly-braces>

3. React, **Your First Component**  
   React 컴포넌트가 UI를 구성하는 방식과 컴포넌트가 JSX를 반환하는 형식을 참고했습니다.  
   <https://react.dev/learn/your-first-component>

4. React, **createElement**  
   JSX와 `createElement()`의 관계, React 엘리먼트가 UI를 설명하는 값이라는 개념을 참고했습니다.  
   <https://react.dev/reference/react/createElement>

5. React, **createRoot**  
   브라우저 DOM 요소에 React root를 생성하는 방법과 `root.render()`의 역할을 참고했습니다.  
   <https://react.dev/reference/react-dom/client/createRoot>

6. React, **Render and Commit**  
   렌더링 촉발, 컴포넌트 렌더링, DOM 커밋과 브라우저 표시 과정을 참고했습니다.  
   <https://react.dev/learn/render-and-commit>

7. React, **React DOM Components**  
   JSX에서 브라우저의 기본 HTML 요소와 속성을 사용하는 방법을 참고했습니다.  
   <https://react.dev/reference/react-dom/components>

## 개발 도구 공식 문서

8. Vite, **Getting Started**  
   Vite 프로젝트 생성 명령, React 템플릿과 개발 서버 실행 절차를 참고했습니다.  
   <https://vite.dev/guide/>

## 웹 표준 및 JavaScript 참고 자료

9. MDN Web Docs, **Introduction to the DOM**  
   HTML 문서와 브라우저 DOM 객체의 관계를 설명할 때 참고했습니다.  
   <https://developer.mozilla.org/en-US/docs/Web/API/Document_Object_Model/Introduction>

10. MDN Web Docs, **Expressions and operators**  
    JSX 중괄호 안에서 사용하는 JavaScript 표현식의 의미를 설명할 때 참고했습니다.  
    <https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Expressions_and_operators>
