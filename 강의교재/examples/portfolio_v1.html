PART 00

파일 만들기

파일 하나HTML 뼈대내부 style

미션

index.html 파일 하나를 만듭니다. CSS는 <head> 안의 <style> 태그에, HTML은 <body> 안에 작성합니다. 파일 하나만 열면 결과가 바로 보입니다. 아래 시작 코드를 그대로 작성하고 시작하세요.

요구사항

  • 파일 하나만: index.html
  • <head> 안에 <style> ... </style>
  • <style> 맨 위에 기본 설정(초기화·배경·글꼴) 작성
시작 파일 (그대로 작성)
index.html새 파일 — 이대로 시작
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>홍길동 · 포트폴리오</title>
  <style>
/* 기본 설정 */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
body {
  font-family: 'Segoe UI', 'Malgun Gothic', sans-serif;
  color: #222222;
  background-color: #ffffff;
  line-height: 1.7;
}
a {
  color: inherit;
  text-decoration: none;
}
.wrap {
  max-width: 960px;
  margin: 0 auto;
  padding: 0 24px;
}
  </style>
</head>
<body>

  <!-- 아래에 PART 1부터 순서대로 HTML을 추가합니다 -->

</body>
</html>
PART 01

네비게이션

flex 양끝sticky
목표 화면 — 이렇게 보이도록 만드세요

미션

화면 맨 위에 로고와 메뉴 바를 만드세요.

요구사항

  • 왼쪽 로고(이름)
  • 오른쪽 메뉴 6개 (소개·기술·경력·프로젝트·블로그·연락처)
  • 스크롤해도 맨 위에 고정
  • 마우스 올리면 메뉴 색 변화

HTML 구조 — 이렇게 만드세요

  • <nav class="nav"> 안에 <div class="wrap nav-inner">
  • 왼쪽 로고 <div class="logo">홍길동</div>
  • 오른쪽 메뉴 <ul> 안에 <li><a href="#about">소개</a></li> 형태로 6개

CSS 지시 — <style> 안에 아래 값 그대로 작성하세요

  • .navborder-bottom: 1px solid #e5e5e5; position: sticky; top: 0; background-color: #ffffff;
  • .nav-innerdisplay: flex; justify-content: space-between; align-items: center; height: 64px;
  • .logofont-size: 20px; font-weight: bold; color: #2f6feb;
  • .nav uldisplay: flex; gap: 24px; list-style: none; font-size: 15px;
  • .nav a:hovercolor: #2f6feb;
PART 02

히어로 — 소개 텍스트

2단 grid버튼
목표 화면 — 이렇게 보이도록 만드세요

미션

첫 화면을 좌우 2칸으로 나누고 왼쪽에 인사말·소개·버튼을 넣으세요. (오른쪽은 PART 3)

요구사항

  • 큰 인사 제목
  • 한 줄 소개 + 소개 문단
  • 버튼 2개 (채운 것 · 테두리 것)

HTML 구조 — 이렇게 만드세요

  • <header class="hero"> 안에 <div class="wrap hero-inner">
  • 왼쪽 <div class="hero-text"> 안에: <h1>인사말</h1>, <p class="role">한 줄 소개</p>, <p class="hero-desc">소개 문단</p>
  • 그 아래 <div class="hero-buttons"> 안에 <a class="btn btn-fill"> 와 <a class="btn btn-line">
  • 오른쪽 자리는 PART 3에서 채웁니다

CSS 지시 — <style> 안에 아래 값 그대로 작성하세요

  • .heropadding: 70px 0;
  • .hero-innerdisplay: grid; grid-template-columns: 1fr 1fr; gap: 40px; align-items: center;
  • .hero h1font-size: 40px; line-height: 1.2; margin-bottom: 12px;
  • .rolecolor: #2f6feb; font-size: 18px; margin-bottom: 16px;
  • .hero-desccolor: #666666; margin-bottom: 24px;
  • .hero-buttonsdisplay: flex; gap: 12px;
  • .btndisplay: inline-block; padding: 12px 22px; border-radius: 8px; border: 1px solid #e5e5e5;
  • .btn-fillbackground-color: #2f6feb; color: #ffffff; border-color: #2f6feb;
  • .btn-fill:hoverbackground-color: #1e54c9;
  • .btn-linebackground-color: #ffffff; color: #222222;
  • .btn-line:hoverborder-color: #2f6feb; color: #2f6feb;

PART 10

푸터 + 반응형

양끝 정렬@media
목표 화면 — 이렇게 보이도록 만드세요

미션

맨 아래 푸터를 만들고, 좁은 화면에서 2열이 1열이 되게 마무리하세요.

요구사항

  • 맨 아래 저작권(왼쪽) + 링크(오른쪽)
  • 좁은 화면에서 히어로·프로젝트가 1열로 바뀌면 완성

HTML 구조 — 이렇게 만드세요

  • <footer class="footer"> 안에 <div class="wrap footer-inner">
  • <span>© 2026 홍길동</span> 와 <span>GitHub · LinkedIn · Blog</span> 두 개

CSS 지시 — <style> 안에 아래 값 그대로 작성하세요

  • .footerborder-top: 1px solid #e5e5e5; padding: 24px 0; color: #999999; font-size: 14px;
  • .footer-innerdisplay: flex; justify-content: space-between;
  • @media (max-width: 720px){ .hero-inner { grid-template-columns: 1fr; } .projects { grid-template-columns: 1fr; } .nav ul { display: none; } }
